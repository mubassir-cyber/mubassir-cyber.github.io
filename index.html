Built to be safe to run

Logs are written by attackers, so the dashboard treats every field as untrusted.

  • Results are inserted as text, never as HTML
  • Strict Content-Security-Policy and security headers
  • 2 MB upload limit; files never touch the disk
  • Sample names come from an allow-list, not a path

The container is locked down and only reachable from your own machine.

  • Runs as a non-root user
  • All Linux capabilities dropped, no-new-privileges
  • Read-only filesystem
  • Port bound to 127.0.0.1 only
